## Request Summary
Implements `MilitaryConflictPhase`: war declaration, entity squad commitment, siege mechanics, and territory transfer via authoritative pipeline.

**Requires:** TCK-20260619-E53B-DIPLOMACY

## Scope

**MilitaryConflictPhase** at governance layer (after `FactionDecisionPhase`):
- War declaration: `FactionDirective(WAR_DECLARED, target_faction)`
- Squad commitment: commit GUARD + WARRIOR entities near contested region via `GroupRecord.roles["FACTION_SQUAD"]`
- Siege mechanics: besieging faction reduces target region's `service_availability` by 5% per tick; defender emits reinforcement directives
- Territory transfer: `RegionSovereigntyUpdate(region_id, new_faction_id)` applied via authoritative pipeline when `siege_progress ≥ 1.0`

**War exhaustion**: `FactionState.military_strength -= 0.001 per tick at war`. Incentivizes peace when `military_strength < 0.3`.

**Combat**: faction squads use standard damage formula from `docs/mechanics/02_combat_laws.md`. Do NOT special-case siege combat.

Scope child standard tickets at implementation time (suggest: (i) MilitaryConflictPhase registration, (ii) squad commitment + siege state model, (iii) territory transfer via authoritative pipeline, (iv) war exhaustion + peace triggers).
