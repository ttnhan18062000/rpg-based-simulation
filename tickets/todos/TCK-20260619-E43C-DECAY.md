## Request Summary
Cross-episode social memory must decay toward neutral over episodes, with grudges decaying slower than cooperations. This ticket implements `SocialMemoryDecay` with separate half-lives.

**Requires:** TCK-20260619-E43B-EXPORT-IMPORT

Can start in parallel with TCK-20260619-E43D-FACTION-MEMORY after E43B.

## Scope

In `src/domains/campaigns/social_memory.py`, add:

```python
class SocialMemoryDecay:
    FRIENDSHIP_DECAY = 0.40    # 40% loss per episode (half-life ~3 episodes)
    GRUDGE_DECAY = 0.10        # 10% loss per episode (half-life ~7 episodes)

    @staticmethod
    def apply_decay(record: SocialMemoryRecord) -> SocialMemoryRecord:
        new_scores = {}
        for entity_id, score in record.relationship_scores.items():
            decay_rate = SocialMemoryDecay.GRUDGE_DECAY if score < 0 else SocialMemoryDecay.FRIENDSHIP_DECAY
            new_scores[entity_id] = round(score * (1.0 - decay_rate), 4)
        new_faction_rep = {
            fid: round(score * (1.0 - SocialMemoryDecay.FRIENDSHIP_DECAY), 4)
            for fid, score in record.faction_reputation.items()
        }
        return replace(record, relationship_scores=new_scores, faction_reputation=new_faction_rep)
```

Call `SocialMemoryDecay.apply_decay(record)` inside `SocialMemoryImporter.apply()` before applying the legacy scores.
