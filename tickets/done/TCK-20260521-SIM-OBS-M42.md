Domain Analyzer Framework (Milestone 42)

## Status

INPROGRESS

## Request Summary

Implement the Phase 8 domain analyzer framework: shared AnalysisContext, DomainFinding model, DomainAnalyzer abstract base, DomainAnalyzerRegistry, and four minimal domain analyzers (movement, economy, quest, runtime).

## Scope

- `src/observability/understanding/` package
- `context.py` — AnalysisContext
- `domain/base.py` — DomainFinding, DomainAnalyzer, DomainAnalysisResult, DomainAnalyzerRegistry
- `domain/movement.py` — MovementDomainAnalyzer
- `domain/economy.py` — EconomyDomainAnalyzer
- `domain/quest.py` — QuestDomainAnalyzer
- `domain/runtime.py` — RuntimeDomainAnalyzer
- Unit and integration tests

## Out of Scope

- Combat/strategy/faction analyzers (deferred per spec)
- Expectation pack integration (M43)

## Acceptance Criteria

- [ ] Analyzer registry runs multiple analyzers
- [ ] Missing signals → SKIPPED_MISSING_SIGNAL (no crash)
- [ ] Movement stuck events → movement finding
- [ ] Economy freeze → economy finding
- [ ] Quest stalled → quest finding
- [ ] Governor degraded → runtime finding
- [ ] Findings include evidence and next steps
- [ ] All tests pass
