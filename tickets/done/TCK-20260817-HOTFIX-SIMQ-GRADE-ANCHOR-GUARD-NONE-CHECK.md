# TCK-20260817-HOTFIX-SIMQ-GRADE-ANCHOR-GUARD-NONE-CHECK

## Request Summary
Part of a batch of 7 tickets fixing genuinely pre-existing CI failures. This one:
`tests/simulation_quality/test_grade_regression.py::test_grade_anchor_file_exists_and_valid` fails
on CI with `TypeError: 'NoneType' object is not subscriptable`.

Root cause (confirmed via investigation): `data/calibration/` is intentionally gitignored
(`.gitignore:240` — regenerated by `calibrate_simq.py`), and CI's `simulation-quality` job never
runs `make calibrate`/`calibrate_simq.py` first — just `pip install` then `pytest`. On a clean CI
checkout, `data/calibration/**/quality_report.json` never exists, so `_load_calibration_report()`
(line 308-316) returns `None` as documented ("allows pytest.skip downstream"). Every other test in
the file correctly checks `if report is None: pytest.skip(...)` (4 existing call sites, e.g. line
345-347). The field-confusion guard block added at the end of
`test_grade_anchor_file_exists_and_valid` (introduced in `29d78798`, "Simulation quality (#20)",
2026-08-14) skips that check and subscripts `guard_report["pillars"][guard_pillar]` unconditionally
— crashing with the observed `TypeError` on any environment without a pre-built local calibration
cache (this repo's own CI, or any fresh clone). Locally the test only passes because a prior manual
`make calibrate` run left an untracked, gitignored `quality_report.json` on disk.

## Scope
- Add the same `if report is None: pytest.skip(...)` guard, matching the file's own existing
  pattern exactly, immediately after `guard_report = _load_calibration_report(guard_run_key)` at
  `tests/simulation_quality/test_grade_regression.py:610`.

## Out of Scope
- Any other of the 7 CI failures in this batch (each has its own ticket).
- Generating/committing real calibration data for CI, or adding a `make calibrate` step to the CI
  workflow — every other test in this file already treats calibration data as an optional local
  artifact via skip-on-missing; this ticket matches that established convention rather than
  introducing a new one.

## Acceptance Criteria
