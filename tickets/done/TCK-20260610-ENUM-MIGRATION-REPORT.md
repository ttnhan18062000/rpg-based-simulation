## Request Summary
Phase 40.3 requires a report (generated by an architecture test) that categorises all remaining direct `Faction`/`EntityRole` enum usage in the codebase. The report distinguishes allowed legacy/test usage from migration targets and from forbidden new usage. It provides file, line, enum symbol, category, suggested replacement, and migration status.

## Scope
- Add `tests/architecture/test_enum_migration_report.py` (or extend the linter test from 40.2)
- Report categories: `allowed_legacy_fallback`, `allowed_test_only`, `compatibility_projection`, `migration_target`, `forbidden_new`
- Report fields per entry: file, line, enum symbol, category, suggested replacement, migration status
- Architecture test asserts: report can be generated, `forbidden_new` category is empty, allowed categories are explicitly listed
- Report output printed on test failure for visibility

## Out of Scope
- Automated fixing of enum usage
- Enforcing migration deadlines

## Acceptance Criteria
- [ ] Report lists all remaining enum usage by category
- [ ] `forbidden_new` category is empty (CI gate)
- [ ] Allowed categories are explicitly listed and non-empty (proves report is working)
- [ ] Report distinguishes runtime source from test files
- [ ] Report provides suggested replacement for each migration target
