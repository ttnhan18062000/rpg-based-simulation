# TCK-20260520-SIM-OBS-M35

## Title

Implement ClickHouse Event Warehouse V1 (Milestone 35)

## Status

DONE

## Request Summary

Extend the RPG simulation observability system to support a production-ready, high-volume event warehouse using ClickHouse. This involves ClickHouse connection configuration, an automatic schema creation/verification manager, batch ingestion routines with idempotency checks, core analytical queries, new CLI pipelines, and robust testing paths that skip integration runs gracefully if ClickHouse is not active.

## Scope

- **Milestone 35.1: ClickHouse Config**:
  - Add ClickHouse connection properties to `ObservabilityConfig` (`host`, `port`, `database`, `username`, `password`, `secure`, `batch_size`).
  - Keep ClickHouse disabled by default and ensure local workflows run without external server requirements.
- **Milestone 35.2: ClickHouse Schema Manager**:
  - Automatically create database and tables (`runs`, `sweeps`, `simulation_events`, `metric_windows`, `anomalies`, `hard_law_violations`, etc.) with correct data types.
- **Milestone 35.3: ClickHouse Ingestion Job**:
  - Implement bulk/batch inserts for runs and sweeps.
  - Enforce safe idempotency: check artifact checksums to skip duplicates and handle updates.
- **Milestone 35.4: ClickHouse Core Queries**:
  - Build analytical query implementations on the ClickHouse adapter (e.g. `worst runs by health`, `common anomalies`, `entity events`).
- **Milestone 35.5: CLI Subcommands**:
  - Register `rpg-observe warehouse init`, `rpg-observe warehouse query worst-runs`, and `rpg-observe warehouse query entity-events --entity-id <id>`.

## Out of Scope

- Setting up external streaming queue consumption daemons (reserved for Milestones 36 and 37).
- Replacing local JSONL files as primary developer artifacts.

## Acceptance Criteria

- [x] ClickHouse integration is strictly optional and disables gracefully if not configured
- [x] Local/CI workloads run with zero ClickHouse server requirements
- [x] Schema manager initializes all required database tables safely without destructive rewrites
- [x] Batch ingestion routines support run/sweep parsing and record mapping cleanly
- [x] Safe, checksum-backed run ingestion idempotency skips matching runs and handles forced rewrites
- [x] ClickHouse integration tests auto-skip gracefully if the service is unavailable
