# TCK-20260520-SIM-OBS-M29-M33

## Title

Implement Live Event Streaming, External Anomaly Worker, Historical API, Retention, and Deployment Profiles (Milestones 29-33)

## Status

standard

chore

## Request Summary

Extend the Live Observatory by implementing the remaining Milestones of Phase 6: Milestone 29 (Event Stream Adapter Interface & optional Redis stream skeleton), Milestone 30 (External Anomaly Worker outside engine process), Milestone 31 (Historical Query API exposing run/sweep history), Milestone 32 (Retention Policy dry-run and clean capabilities), and Milestone 33 (Deployment Profiles & Scale validation).

## Scope

- **Milestone 29: Event Stream Adapter**:
  - Define `EventStreamAdapter` interface (`publish`, `publish_batch`, `health`, `flush`, `close`).
  - Implement `NullEventStreamAdapter` and `InProcessEventStreamAdapter` (routing to `LiveEventPublisher`).
  - Implement optional `RedisStreamAdapter` skeleton (publishing JSON to Redis Streams with connection failure safety).
  - Add configuration resolvers in `src/observability/config.py`.
  - Let `EventRecorder` depend on `EventStreamAdapter`.
- **Milestone 30: External Anomaly Worker**:
  - Implement `ExternalAnomalyWorker` running in artifact mode (loads run artifacts, executes analyzer pipeline / rule engine, outputs `anomalies.json` and updates status).
  - Register new subcommand `rpg-observe worker analyze-run <run_id>`.
- **Milestone 31: Historical Query API**:
  - Implement `HistoricalRunQueryService` and `HistoricalSweepQueryService`.
  - Register `/observability/history/*` endpoints in a new FastAPI router, mounted safely.
  - Implement simple pagination and limits.
- **Milestone 32: Retention and Data Lifecycle Policy**:
  - Implement `RetentionPolicy` and `RetentionManager` classifying runs and calculating cleanups.
  - Add CLI subcommands `rpg-observe retention plan` and `rpg-observe retention clean --confirm`.
- **Milestone 33: Deployment Profiles and Scale Validation**:
  - Define profile models and validation rules.
  - Create standard profiles (`Local Developer`, `CI / Certification`, `Long-Run Lab`).
  - Implement a scale validation harness measuring overhead.

## Out of Scope

- A full ClickHouse/Kafka production stack.
- Continuous auto-retention daemon process.
- Live user authorization and access control roles.

## Acceptance Criteria

- All EventStreamAdapter backends behave correctly; Redis backend is connection-resilient and does not crash simulation loop when offline.
- External Anomaly Worker runs cleanly in standalone CLI mode.
- Historical API routes fetch past run/sweep outputs correctly.
- Retention manager produces dry-run plan, deletes only unprotected runs on explicit confirmation, and respects failed/critical protection.
- Profiles resolve dynamically; CI profile requires no external dependencies.
- Parity is maintained: All unit, API, integration, and performance tests pass successfully.
