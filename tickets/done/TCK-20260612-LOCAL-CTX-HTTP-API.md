# TCK-20260612-LOCAL-CTX-HTTP-API

## Title
Local FastAPI Search Server for Agent Tool Use (`POST /api/search`)

## Status
DONE

## Tier
standard

## Type
feature

## Priority
P2

## Request Summary
The CLI tool from `TCK-20260612-SEMANTIC-KNOWLEDGE-SEARCH` works for single queries in a shell, but agents working in an automated pipeline benefit from an HTTP interface: they can call a stable endpoint, get structured JSON back, and compose queries without subprocess overhead. This ticket adds `tools/search_server.py` — a local FastAPI service that loads the same `knowledge-index/` built by `knowledge_search.py` and exposes `POST /api/search` and `GET /api/health`. It runs on `localhost:8765` and is registered in `CLAUDE.md` as an agent proactive tool so future agents know to call it before answering architecture or mechanic questions.

## Scope
- New file: `tools/search_server.py`
  - FastAPI app, starts with `uvicorn tools.search_server:app --port 8765`
  - Loads `knowledge-index/knowledge.db` (vectors) and `knowledge-index/bm25.pkl` (keyword) at startup; fails fast with a clear error if either is missing
  - `POST /api/search` — hybrid search (same logic as `knowledge_search.py query --mode hybrid`)
  - `GET /api/health` — readiness check
- Request schema (`POST /api/search`):
  ```json
  {
    "query": "string (required)",
    "top_k": "integer, default 8",
    "filters": {
      "section": "string (optional) — one of: mechanics, engine, core, strategy, architecture, guidelines, etc.",
      "mode": "hybrid | vector | keyword (optional, default hybrid)"
    },
    "include_text": "boolean, default false"
  }
  ```
- Response schema:
  ```json
  {
    "query": "string",
    "top_k": 8,
    "results": [
      {
        "doc_id": "mechanics/02_combat_laws#h2-damage-formula-001",
        "title": "Combat Laws",
        "heading": "Damage Formula",
        "source_path": "docs/mechanics/02_combat_laws.md",
        "section": "mechanics",
        "score": 0.84,
        "semantic_score": 0.79,
        "keyword_score": 0.62,
        "excerpt": "first 200 chars of chunk text",
        "text": "full chunk text (only if include_text=true)"
      }
    ]
  }
  ```
- Health response (`GET /api/health`):
  ```json
  {
    "status": "ok",
    "index_version": "<mtime of knowledge.db as ISO8601>",
    "documents": 1840,
    "chunks": 2310,
    "model": "sentence-transformers/all-MiniLM-L6-v2"
  }
  ```
- Add `make search-server` target to `Makefile`:
  ```makefile
  search-server: ## Start local knowledge search server on :8765
      uvicorn tools.search_server:app --port 8765 --reload
  ```
- CORS: restrict to `localhost` origins only (no public exposure)
- Add a tool-use entry to `CLAUDE.md` under **Proactive Tool Use → Always auto-invoke**:
  ```
  | `tools/search_server.py` running on :8765 | Before answering project-specific mechanics or architecture questions, call `POST http://localhost:8765/api/search` with the question as the query |
  ```
  (Add a note that the CLI fallback `python3 tools/knowledge_search.py query "<q>" --top-k 5` should be used when the server is not running.)

## Out of Scope
- Authentication or API tokens (internal localhost only)
- Rate limiting (single developer, local use)
- Query logging / analytics (follow-up in evaluation ticket)
- Deployment outside localhost
- OpenAPI schema publication (auto-generated by FastAPI at `/docs`)
- Async embedding (queries are synchronous; latency is acceptable for single-agent use)

## Assumptions / Open Questions
- Port 8765 is chosen to avoid conflicts with common dev servers (3000, 8000, 8080, 5000); change if already in use
- The server shares retrieval logic with `knowledge_search.py` by importing it — do not copy-paste the search code
- `sentence-transformers` model is loaded once at startup; query latency target is under 500ms for top-k=8 on CPU

## Implementation Notes

- `search_server.py` uses `importlib.util` to load `knowledge_search.py` from sibling path; checks `sys.modules` first so test stubs are respected
- Lifespan skips startup when `_APP_STATE.ready=True` (injected by test fixture), enabling TestClient without real index
- Lifespan enters graceful degraded mode (503 on all endpoints) when index directory is missing, rather than crashing — cleaner than RuntimeError for production use
- `tools/search/` directory created for Docker assets; Dockerfile pre-bakes `all-MiniLM-L6-v2` into image layer
- Test fix: `ready_state` fixture must set `mock_model.encode.return_value.tolist.return_value = [0.0] * 384` (not a plain list) because the server calls `.tolist()` on the encode result; `test_search_returns_results_shape` patches `_mod.sqlite3` and `sys.modules["sqlite_vec"]` to avoid virtual-table requirements in the test environment
