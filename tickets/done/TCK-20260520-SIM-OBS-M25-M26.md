# TCK-20260520-SIM-OBS-M25-M26

## Title

Lightweight Live Anomaly Counters and Minimal Developer Observatory View

## Status

DONE

## Request Summary

Implement Milestone 25 (Lightweight Live Anomaly Counters) and Milestone 26 (Minimal Developer Observatory View) to complete Phase 5 of the Live Observatory.

## Scope

- Implement a thread-safe, memory-efficient `LiveAnomalyCounter` (and/or health calculator) that dynamically subscribes to the `LiveEventPublisher` to track simulation anomalies, events by type, events by severity, and resets per run.
- Keep track of rolling counters: `hard_law_violation_count`, `navigation_stuck_count`, `governor_degraded_ticks`, `dropped_event_count`, `error_event_count`, `critical_event_count`.
- Support configurable threshold rules for raising alert severity (HEALTHY, WARNING, DEGRADED, CRITICAL).
- Expose health status through a new FastAPI REST endpoint `GET /api/v1/observability/live/health`.
- Design and implement an ultra-premium, dark-themed, glassmorphism-based single-page Developer Observatory UI served at `GET /api/v1/observability/ui` (and `GET /observability/ui` redirect) that connects to the live events WebSocket and displays run status, real-time counters, event streaming log, and the entity inspector search panel.
- Ensure all endpoints are fully read-only and present no simulation mutation controls.
- Write extensive unit and API integration tests covering all functionality.

## Out of Scope

- Integrating a full historical time-series analytics engine or ML-based anomalies.
- Building a complex multi-page dashboard or external database warehouse.

## Acceptance Criteria

- `LiveAnomalyCounter` accurately tracks and increments counts on incoming simulation events.
- Health state transitions to `CRITICAL` on hard law violations and `WARNING`/`DEGRADED` on stuck navigation or degraded governor mode.
- REST endpoint `GET /api/v1/observability/live/health` returns status, reasons, and detailed counters.
- Serving `GET /api/v1/observability/ui` returns an extremely polished, high-performance HTML/JS/CSS client-side dashboard.
- The UI panel displays real-time tick/tps status, event ticker, and an interactive entity inspector.
- All test suites pass successfully.
