# TCK-20260627-P2M-CI-ARTIFACTS

## Title
Upload `reports/certification/` as CI artifact in `slow` job

## Status
DONE

## Tier
hotfix

## Type
chore

## Priority
P2

## Request Summary
`reports/certification/` and `reports/release_proof/` are local ephemeral outputs. CLAUDE.md §After Work instructs `rm -rf reports/release_proof/*`. No CI artifact preserves these per commit SHA, so certification evidence is lost after each local run. Source: D18 F5, Risk 5/15.

## Scope
- Add an `actions/upload-artifact` step to the `slow` job in `.github/workflows/test.yml`.
- Archive `reports/certification/` as a CI artifact named `certification-report-{commit-sha}` (or similar).
- Retention: 30 days (GitHub default) or match existing CI conventions.

## Out of Scope
- Uploading `reports/release_proof/` (those are ephemeral by design per CLAUDE.md).
- Changing the certification harness itself.

## Acceptance Criteria
- [x] `.github/workflows/test.yml` `slow` job includes an `actions/upload-artifact@v4` step after the certification run.
- [x] Artifact name includes the commit SHA or run ID for traceability.
- [x] Artifact path is `reports/certification/`.
- [x] The upload step uses `if: always()` so artifacts are preserved even on test failure.

## Implementation Notes
Added `actions/upload-artifact@v4` step to the `slow` job in `.github/workflows/test.yml`, after the `Legacy regression` step. The step uses `if: always()` so the artifact is uploaded even when tests fail, archives `reports/certification/` under the name `certification-report-${{ github.sha }}`, and retains for 30 days. No other files changed.

```yaml
- name: Upload certification report
  uses: actions/upload-artifact@v4
  if: always()
  with:
    name: certification-report-${{ github.sha }}
    path: reports/certification/
    retention-days: 30
```
