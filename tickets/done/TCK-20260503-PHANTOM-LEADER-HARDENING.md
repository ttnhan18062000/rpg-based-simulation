## Request Summary
Ensure that group cohesion and leadership dissolution reflect real-time entity status (death/active) within the same simulation tick.

## Scope
- Modify `AuthoritativeApplyPipeline.refine` to pass the `working_state` (sliding state) to the `GroupSystem`.
- Ensure `GroupSystem.update_groups` detects leader death immediately after the combat phase.

## Out of Scope
- Changing how groups are formed (recruitment logic).
- Modifying group movement AI.

## Acceptance Criteria
- [x] If a leader dies in `CombatResolutionSystem`, the group must dissolve or enter "Leaderless" state in the same tick.
- [x] Group member intents for the following tick must reflect the dissolved state immediately.
