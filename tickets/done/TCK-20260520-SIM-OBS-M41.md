# TCK-20260520-SIM-OBS-M41

## Title

Production Readiness Validation (Milestone 41)

## Status

DONE

## Request Summary

Prove that the V2 Observatory platform works without damaging the engine by implementing failure injection tests, overhead benchmarks, and generating a formal production readiness report.

## Scope

- Define production readiness criteria (overhead thresholds, failure behaviors)
- Implement `ProductionReadinessHarness` for orchestrating validation scenarios
- Implement failure injection tests: stream outage, warehouse outage, worker crash, high event volume, webhook failure
- Measure observatory overhead (tick p95, memory)
- Generate a structured readiness report
- Validate alert routing under failure conditions

## Out of Scope

- Actual Redis/ClickHouse cluster deployment (tested via mocking/simulation)
- Scaling to 1000+ entities with 50,000 ticks (adjusted to fast-CI-compatible scenarios)

## Acceptance Criteria

- [ ] Production readiness criteria documented
- [ ] Failure injection tests exist and pass
- [ ] Readiness report generated
- [ ] Stream outage is safe (engine continues)
- [ ] Warehouse outage is safe (local artifacts preserved)
- [ ] Worker crash is safe (engine continues, alert generated)
- [ ] Engine performance remains acceptable
