# Agent Monitoring

Append-only store for workflow run records and per-agent event records. Used for weekly retrospectives and health monitoring of the AI agent workflow.

**Not engine monitoring** — this tracks Claude Code agents (implement-ticket workflow, etc.), not the RPG simulation engine.

## Files

| File | Description |
|---|---|
| `runs.jsonl` | One record per workflow invocation |
| `events.jsonl` | One record per agent call; joined to runs by `run_id` |
| `tools.jsonl` | One record per tool call; joined to events by `run_id` + `seq` |
| `retro/` | Weekly retro reports generated by `make agent-monitoring-retro` |

## Schema

### runs.jsonl

| Field | Type | Description |
|---|---|---|
| `run_id` | string | Ticket ID (e.g. `TCK-20260607-...`) |
| `start_ts` | ISO 8601 | When the workflow started |
| `end_ts` | ISO 8601 \| null | When it finished; null = crashed/incomplete |
| `workflow` | string | Workflow name (e.g. `implement-ticket`) |
| `tier` | string | `hotfix` \| `standard` \| `epic` |
| `final_status` | string | `DONE` \| `CONFLICTS_DETECTED` \| `EPIC_SCOPED` \| `NEEDS_HUMAN_INPUT` \| `NEEDS_CHANGES` \| `BLOCKED` \| `TESTS_FAILED` \| `DOD_BLOCKED` \| `CRASHED` \| `IN_PROGRESS` |
| `agent_count` | int | Number of agent calls in this run |
| `duration_s` | int \| null | Total duration in seconds |

### events.jsonl

| Field | Type | Description |
|---|---|---|
| `run_id` | string | FK → runs.run_id |
| `seq` | int | Call order within the run (1-based) |
| `ts` | ISO 8601 | Timestamp of this event |
| `phase` | string | Workflow phase (e.g. `Investigate`) |
| `agent` | string | Agent name (e.g. `investigator`) |
| `summary` | string | One sentence from the agent describing what it did and the key finding. Empty = prompt quality issue. |
| `status` | string | `ok` \| `failed` \| `blocked` \| `skipped` |
| `tool_call_count` | int \| null | Total tool calls made by this agent; computed from tools.jsonl by writeMonitoring. null for runs before this field was added. |

### tools.jsonl

One record per tool call, written by `PreToolUse` + `PostToolUse` hooks. Joined to events by `run_id` + `seq`.

| Field | Type | Description |
|---|---|---|
| `session_id` | string | Claude Code session ID (from hook payload) |
| `run_id` | string \| null | FK → runs.run_id; null when tool call occurs outside a workflow run |
| `seq` | int \| null | FK → events.seq within the run; null outside workflow or before sidecar is written |
| `ts` | ISO 8601 | Timestamp of the tool call (PostToolUse) |
| `tool` | string | Tool name: `Read`, `Edit`, `Write`, `Bash`, `Agent`, etc. |
| `input_summary` | string | Key identifier from tool input: file path for Read/Edit/Write, first 80 chars of command for Bash, description for Agent |
| `status` | string | `ok` \| `failed` |
| `duration_ms` | int \| null | Wall-clock milliseconds from PreToolUse to PostToolUse |

## Tools

```bash
make agent-monitoring-retro      # generate weekly report
make agent-monitoring-validate   # check integrity
make agent-monitoring-query ARGS="--agent investigator --status failed"
```
