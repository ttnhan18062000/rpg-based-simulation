   real, now-measured compliance gap, not just a documented rule — worth a follow-up ticket to
   trace which specific agent role (investigator vs. hand-orchestrated Investigate phases) is
   driving the non-compliant majority, since the fix differs (agent prompt vs. session-level
   habit).

3. **2 unsafe `parity_index.py build` invocations** (real repo path) flagged by the same new
   audit section, with 0 safe co-occurrences (`docs/parity_ledger/*.yaml` edit + same-run

   runs (not resolvable from `query.py --summary-contains` alone — the audit's own detection
