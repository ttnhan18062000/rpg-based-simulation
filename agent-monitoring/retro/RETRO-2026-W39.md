**Correction to this section's first review.** Its action ("put the bare-directory requirement in
`test-scoper`'s own prompt; delete the `tickets/todos/` duplicate before Verify") was half wrong, and
the other half pointed at the operator instead of the pipeline:

  deliberately copies the ticket and leaves the `tickets/todos/` original. Finalize deletes it, and
  Verify runs in between without ever being told. There are **6 BLOCKs** of this shape all-time.
  Deleting the copy "before Verify" by hand races the pipeline's own cleanup.

**Action:** `TCK-20260927-PHASE-PROMPTS-OMIT-GATE-PRECONDITIONS`. The orchestrator injects the
required test directories before the Test agent runs, and declares the expected `tickets/todos/` path
to Verify. Both gates are unchanged. **Re-count both figures (7 / 6) at the next retro;** that is the
"after" figure for the ticket.

**Method note.** The first scan for these counts gave 8 and 7, and each included one keyword false
match (a summary containing "bare", and a folder-archival BLOCK containing "todos"). The two sessions
each caught a different one. Classify failure events by what the summary says, not by keyword hits.
