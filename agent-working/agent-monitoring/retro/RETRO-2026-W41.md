  `.claude/settings.json` lacks 46 lines of hooks that are on main. The missing hooks are the session-roles

  `session_start_hook.py` role binding. Evidence:

    worktree (the files are not gitignored);
  - `session_role` is `unresolved` on 59/59 W41 runs and `None` on all 1321 W41 tool rows;
  - this very session began with the owner typing a role reminder ("continue as agent-working-design").

  Also, the guard only emits deny/ask, never allow. Prompts for force-push and `gh pr create` therefore come
  from the static `permissions.ask` list and the missing `gh pr create` allow rule, which the guard ticket
  did not touch.
- **Durations: 0 min average is an artifact.** 57/59 runs are hand closures with `start_ts == end_ts`. The

  - only 136/238 have a tools shard in their worktree at all, which is the ceiling for any derived time or
    cost.

  The epic is in flight (child 1 closed). The owner decided 2026-10-06 that derived durations stay out of
  headline averages.
- **Spend proxy: 2 of 342 events scored (0.6%), both 0.0.** It was 13.8% in W40 and 18.3% in the 2026-10-01
  regen. That is a drop, not a trend in the work. No pipeline run completed this week, and hand closures have
