## Request Summary
`tests/unit/worldassembly/test_corpus_diversity.py`'s `-m slow` suite (32 tests) never ran to
completion on real CI before today (blocked first by upstream CI failures, then by the real
`Makefile` `$(PYTHON)` discovery bug fixed this session as
`TCK-20260817-HOTFIX-MAKEFILE-PYTHON-DISCOVERY-BROKEN-ON-CI`). Now that it runs for real, 10 of
32 tests fail — a first-time-ever real signal, not a regression from today's work. This ticket
covers 4 of those 10, each independently investigated and confirmed to be a stale/self-
contradictory anchor rather than a real behavior regression:

1. `test_urban_political_seed42_200t_social_grade_stability` (SOCIAL)
2. `test_urban_political_selfmodel_probe_seed42_200t_social_world_grade_stability` (SOCIAL)
3. `test_frontier_living_world_seed42_200t_social_grade_stability` (SOCIAL)
4. `test_unit_selfmodel_pilot_seed42_1000t_cognition_economy_narrative_grade_stability` (NARRATIVE)

The other 6 failing tests are covered by 3 sibling tickets from the same investigation batch:
`TCK-20260817-STANDARD-SIMQ-NARRATIVE-EVENT-EMISSION-REGRESSION-FRONTIER` (5 tests, a real
regression — explicitly NOT a recalibration),
`TCK-20260817-STANDARD-SIMQ-COGNITION-BIT-IDENTICAL-GUARD-TOLERANCE-CONVERSION` (1 test), and
the co-discovered but causally-unrelated `TCK-20260817-STANDARD-SPAWN-OCCUPANCY-COLLISION-RNG-
ROOT-CAUSE` (not a `-m slow` test failure itself).

## Scope
- Tests 1–3 (SOCIAL, `urban_political`/`urban_political_selfmodel_probe`/`frontier_living_world`
  seed42_200t): each test's hardcoded `anchors` dict was authored with a stale SOCIAL score
  literal that was never synced with `tests/simulation_quality/fixtures/grade_anchors.json`'s
  correct value, even though both files were committed in the same commit (`29d78798`,
  "Simulation quality (#20)", 2026-08-14). Sync the literal to the fixture's value and derive a
  fresh evidence-based `abs_floor` from real trial data (1.3x the largest single-sample
  deviation from the anchor, floored at `SCORE_TOLERANCE_ABS_FLOOR=0.05`, per this file's own
  established methodology).
- Test 4 (NARRATIVE, `unit_selfmodel_pilot_seed42_1000t`): the 0.3715 anchor predates
  `TCK-20260807-QUEST-EVENT-TYPE-FILTER-BUG` (fixed 2026-08-07), which removed ~700 events per
  run that were previously mislabeled AI-goal-transition churn counted as fake quest activity.
  Post-fix, this world's profile does not enable `ENABLE_GUILD_QUEST_GENERATION`
  (`TCK-20260807-QUEST-GUILDACTION-DEAD-WIRING`, default OFF), so real quest events are
  correctly 0 for this world. Recalibrate to the real near-zero value — do **not** force quest/
  narrative activity to make the old anchor pass (per this repo's established SimQ-fix
  discipline: investigate whether a low/zero score is a bug or correct behavior before touching
  it).

## Implementation Notes
For each of tests 1–3, synced the hardcoded SOCIAL anchor `score` to the value already committed
in `grade_anchors.json` (same commit, `29d78798`, never propagated to this file), then derived
`abs_floor` as `1.3 * max(|sample_i - new_anchor_score|)` across the fresh trial samples gathered
during investigation:
- `urban_political_seed42_200t`: anchor 7.525 → 16.815; samples (6, 2 runs)
  `[15.61, 16.47, 15.61, 18.355, 13.565, 13.885]`; max deviation 3.25 → `abs_floor=4.225`.
- `urban_political_selfmodel_probe_seed42_200t`: anchor 7.525 → 17.895; samples
  `[14.2, 12.065, 17.39]`; max deviation 5.83 → `abs_floor=7.579`.
- `frontier_living_world_seed42_200t`: anchor 4.9625 → 33.7; samples
  `[33.725, 36.685, 37.84]`; max deviation 4.14 → `abs_floor=5.382`.

For test 4 (NARRATIVE, `unit_selfmodel_pilot_seed42_1000t`), grade threshold table
(`src/simulation_quality/pillars.py:85-91`) maps a score of 0.0 to grade B (boundary), matching
the anchor's existing grade B (kept unchanged — only score/abs_floor were stale). Samples
`[-0.001, 0.0, 0.0]`; max deviation from 0.0 is 0.001 → `1.3*0.001=0.0013`, floored at the
standard `SCORE_TOLERANCE_ABS_FLOOR=0.05` → `abs_floor=0.05`.

Each new anchor's value and rationale is recorded as an inline comment at its dict definition in
`test_corpus_diversity.py`, citing this ticket.
