## Title

## Status

DONE

## Tier
standard

## Type
chore

## Priority
P1

## Request Summary

Implement deterministic, channeled looting of ground items and corpses. Ensure authoritative world object removal and item addition without duplication.

## Scope

- Implement `GroundItemState` and `CorpseState` models.
- Implement `LootAction` for initializing the looting channel.
- Implement `LootSystem` for progress tracking and authoritative handoff.
- Update `ApplyPath` to handle world object removal.
- Add contract tests for looting duration and interruption.

## Out of Scope

- Harvesting resource nodes (Task 6.3).
- Complex loot tables (Task 6.4).

## Acceptance Criteria

- [x] Looting takes a defined number of ticks (default 10).
- [x] Items are removed from the world in the same tick they are added to inventory.
- [x] Multiple entities cannot loot the same item (first completion wins).
- [x] Proximity is enforced throughout the looting duration.
- [x] All tests in `tests/inventory/test_loot_channeling.py` pass.
