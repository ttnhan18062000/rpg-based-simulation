# Investigation
The Gates section is the pattern: `render_section` with a dark wording when the instrument has no rows in any week, a separate wording for an empty period, and `generate()` gated on the rendered string. Runs without the new keys are `predates`, counted apart (same rule as the session_role split); the unstated share is over runs that carry the fields only. Events join to runs by `(run_id, execution_id)`, falling back to `run_id` for a record with no execution id, because the pipeline writes several checkpoint rows per execution.
