# Investigation — TCK-20260930-DONE-CHECKER-DISPOSITION-CLOSURES

## What fails today
`done_checker_static.py`'s `check_migration_complete()` requires `plan.md`, `investigation.md` and
`test_plan.md` in `stored_artifacts/<id>/` for any non-hotfix, non-epic ticket. A standard-tier
ticket closed with nothing built (STALE-PREMISE at `791e6bf6b`) has none, so `migration_complete`
FAILs with no honest way through. The `[precheck]` false-FAILs first reported were already fixed by
#261 (precheck is skipped once a ticket resolves under `tickets/done/`).

## Parsing constraint that shapes the field
`ticket_field_values.py::check_body_field_enum` exact-matches `generate_registry.py::
parse_body_section`, which returns a whole `## ` section body, not its first line. A single
"value, then rationale" section would therefore never equal an enum value. Hence two sections:
`## Disposition` (bare value, validated unchanged) and `## Disposition Rationale` (prose). The
section regex `^## Disposition\s*\n` does not match `## Disposition Rationale` (after the word
comes a space and more text, not a line end), so the two parse independently; pinned by a test.

## REGISTRY.yaml write path
Only one place writes it inside the checker: `check_registry_entry_regenerated()` calls
`generate_registry(root, docs/REGISTRY.yaml)`. Callers of `run_finalize_selfcheck`: the formal
pipeline (`.claude/workflows/implement-ticket.js:1829`, relies on the regeneration) and the CLI.
So the fix is a `regenerate` switch: default True for the function (pipeline unchanged), False for
the CLI unless `--regenerate-registry`. Read-only mode generates to a temp dir and checks the
on-disk file as-is, FAILing with the fixing command when the disk file lacks the ticket's
`tickets/done/` entry.

## src/ attribution
Reuses `_git_touched_paths()` (the ticket's own commits via `--grep=^<id>:` since `origin/main`,
plus uncommitted paths), filtered to `src/`. Uncommitted paths are included so a disposition
closure cannot pass before an edit is committed; in a shared worktree that can over-report, which
fails closed like the docs-coverage check.

## Evidence citation
Accepted forms: a commit SHA (7-40 hex chars containing a digit and a letter, so ordinary words
like "defaced" do not count), a `file:line` reference, or a fenced block of pasted run output.

## Decisions
- Value list unchanged from the ticket (classification epic vocabulary); no extra value needed
  for UNDECLARED: those tickets are not closed as dispositions, they stay open for a spec.
- CLAUDE.md untouched. Its "After Work" text says the registry is regenerated by the Finalize
  self-check with no manual step; that is still true for the pipeline, but a hand-closer now
  passes `--regenerate-registry`. Flagged to agent-working-design for the user's decision.
