### Step 1 — Write `tools/generate_registry.py`

**File:** `tools/generate_registry.py`

**Imports:** Reuse `extract_frontmatter` and `detect_content_type` from `tools/validate_frontmatter.py` (import as a module — same package, no subprocess needed).

**CLI interface:**
```
python3 tools/generate_registry.py [--root <dir>] [--output <path>]
```
Defaults: `--root .`, `--output docs/REGISTRY.yaml`.

**Internal structure:**

```
generate_registry(root: Path, output: Path) -> int
  doc_entries = collect_docs(root)          # walk docs/, skip archive subdirs
  ticket_entries = collect_tickets(root)    # walk tickets/done/*.md
  all_entries = sort_entries(doc_entries + ticket_entries)
  write_yaml(output, all_entries)
  print_summary(all_entries)
  return 0 if no doc_errors else 1

collect_docs(root) -> (list[dict], list[str])
  # Returns (entries, errors)
  # Walk root/docs/ recursively, skip archive/superpowers/specs subdirs
  # For each .md: extract_frontmatter(), detect_content_type()
  # If frontmatter missing: add to errors list (CI gate)
  # Build doc entry dict from frontmatter + H1 title extraction

collect_tickets(root) -> list[dict]
  # Walk root/tickets/done/*.md (flat)
  # For each .md: extract_frontmatter() — missing = warning, not error
  # Parse body sections: Title, Tier, Type, Priority, Related Code Areas
  # Join artifact_files from stored_artifacts/{ticket_id}/
  # Build ticket entry dict

parse_body_section(body: str, section: str) -> str
  # Extract text of a ## Section up to the next ## heading
  # Returns stripped text of the section, or "" if not found

parse_related_code_areas(section_text: str) -> list[str]
  # Extract backtick-quoted tokens from each list item line
  # Pattern: r'`([^`]+)`'
  # Skip lines with no backtick-quoted token

parse_h1_title(body: str) -> str
  # Find first line matching r'^# (.+)' after frontmatter block
  # Return the capture group stripped

join_artifact_files(root: Path, ticket_id: str) -> list[str]
  # Check root/stored_artifacts/{ticket_id}/*.md
  # Return sorted list of relative paths from root
  # Return [] if folder absent

sort_entries(entries: list[dict]) -> list[dict]
  # Primary: type — doc (0) before ticket (1)
  # Within doc: authority P0(0)/P1(1)/P2(2), then path asc
  # Within ticket: date desc (empty date = "0000-00-00" for sort key), then path asc
```

**Doc entry output fields:**
`type`, `path`, `title`, `status`, `layer`, `authority`, `audience`, `tags`, `last_verified`

**Ticket entry output fields:**
`type`, `path`, `ticket_id`, `title`, `tier`, `type` (renamed `entry_type` internally to avoid collision with Python built-in), `priority`, `date`, `related_code_areas`, `artifact_files`, `tags`

Note: the YAML key is `type` for both doc type and ticket type fields. Use a Python-level rename internally (`tier_type` or `ticket_type`) but emit as `type` in YAML.

**Exit codes:** 0 = success, 1 = one or more doc files missing frontmatter.

**YAML output:** Use `yaml.dump(entries, stream, default_flow_style=False, allow_unicode=True, sort_keys=False)` with a header comment:
```yaml
# docs/REGISTRY.yaml — generated by tools/generate_registry.py
# Do not edit manually. Regenerate with: make docs-registry
# Generated: <ISO timestamp>
```

## Architecture Notes

- `generate_registry.py` is a pure read tool — it reads files, writes one YAML output, no durable state mutation.
- It imports from `validate_frontmatter.py` which is already tested and stable.
- `docs/REGISTRY.yaml` is a committed, regeneratable artifact. It is the index — agents read it, they do not scan the source directories it was built from.
- No new enum values, no parity ledger impact, no mechanics law changes.
- No `stored_artifacts/` is walked directly at any point.
