Guards of the icon preview fixture (tests/visual_assets/test_icon_draft_fixture.py), each a test that plants the change in a copy and checks icon_draft_fixture.differences():
flipped PNG byte ............. caught (the PNG's name is reported)
changed manifest entry ....... caught (draft_preview_manifest.json differs, registry_hash ignored)
missing PNG .................. caught (files differ)
changed registry_hash alone .. NOT caught, by design (planner-approved): a key registration must not break an art guard; draft_set_hash is the file hash of draft_set.json and holds no registry hash.
