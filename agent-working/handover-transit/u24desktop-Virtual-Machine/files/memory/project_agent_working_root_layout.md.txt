**How to apply:** memory entries and handover notes written before 2026-10-03 may name old paths; translate with the prefix rule before grepping. A running session's `search_docs` server still points at the old index until restarted (`make knowledge-index-update` rebuilds under `.index/`), so an empty search_docs result right after the move is a local index problem, not proof of absence. Old-root index folders in an old worktree are ignored now (#293) but can hold rows the new shard lacks: diff before deleting. See [[project_search_docs_index_is_per_worktree]].
