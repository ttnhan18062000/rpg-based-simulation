A ticket that turns out to need nothing built (duplicate, false premise, won't-do) closes normally
into `agent-working/tickets/done/` using two body sections — **not** by deleting the file.

- `## Disposition` — one bare value: `STALE-PREMISE`, `NO-MECHANISM`, `DUPLICATE`, `SUPERSEDED`,
  `WONT-DO`.
- `## Disposition Rationale` — prose that must cite at least one commit SHA, `file:line`, or fenced
  run output.

With both valid and no `src/` change attributed to the ticket, `done_checker_static.py`'s
`migration_complete` passes **without** `plan.md`/`investigation.md`/`test_plan.md`.

Built by `TCK-20260930-DONE-CHECKER-DISPOSITION-CLOSURES`. Enum: `tools/ticket_field_values.py`
(`DISPOSITION_VALUES`). Waiver: `tools/gate_checks/done_checker_static.py`
(`_disposition_migration_result`). Guide: `docs/guides/delivery_process.md`, "Closing a ticket with no
implementation". List every existing use with
`grep -A1 '^## Disposition$' agent-working/tickets/done/*.md`.

Still required for a disposition close: the working_log row and monitoring records, via
`record_hand_orchestrated_closure.py` (needs `--title` and `--log-summary` as well as `--ticket-id`,
`--tier`, `--events`). Verify with `done_checker_static.py --ticket-id <ID>`.

**Why this is saved as a trap, not just a fact.** On 2026-10-03 I deleted a confirmed-duplicate
ticket outright and reported the missing mechanism to `agent-working-design` as a process gap. The
mechanism already existed in my own worktree. My reasoning was: `## Status` has only
`OPEN|INPROGRESS|BLOCKED|DONE` (+`EPIC_SCOPED`), therefore no retirement path exists. **`## Disposition`
is a separate body section by design**, so the Status enum says nothing about it. Three disposition
closures were already in `done/`, and the ticket I was closing cited one of them by name in its own
Assumptions ("the camp `STALE-PREMISE` closure") — I read that phrase and did not connect it.

Deletion is the real cost: it drops the ticket out of `docs/REGISTRY.yaml` and every grep over
`agent-working/tickets/`, so only git history holds it.

**How to apply:** never delete a ticket to retire it. Before reporting any mechanism as absent, search
for the mechanism by name, not for a value in the nearest enum — and grep `done/` for how the situation
was handled before. This is the same error shape as
[[feedback_absent_from_sample_is_not_unreachable]]; see also
[[feedback_check_recorded_decision_before_filing_defect]] and
[[feedback_report_agent_process_issues_to_agent_working_design]].
