A draft that removes lines from `tickets/working_log.csv` must name every test that pins physical line numbers of the real log, not just the ratchet/probe tests. `tests/tools/test_validate_working_log.py` pins line numbers of the real log; my 56-line dedupe draft (PR #277, 2026-10-01) missed it, CI failed, and the implementer repinned.

**Why:** the scoped test list in my README came from the checks I had read, not from a search for who reads the file by line number.

**How to apply:** before handing off a data-file edit, grep `tests/` for the file's path plus `by_line`/`expected_lines`, and put those tests in the README's test list. Related: [[feedback-agent-tooling-checks-proportionate]]. Closure events written under a custom agent name also trip the `vocabulary_drift` ratchet; use the closure tool's default agent ("claude").
