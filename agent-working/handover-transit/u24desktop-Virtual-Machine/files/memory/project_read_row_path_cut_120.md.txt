`post_tool_hook._input_summary` stores a Read's absolute `file_path[:120]`; measured 2026-10-02 on W40 shards: 15,921 of 43,776 Read rows (36%) are cut, 12,645 (29%) have no run_id (sidecar missing). A long worktree prefix cuts many test paths.

**Why:** the Architecture-Verify evidence check (`tools/agent-monitoring/arch_verify_read_check.py`, merged in #282) can only say READ / POSSIBLY-READ / NOT-READ / UNATTRIBUTED. Recording the repo-relative path would shrink the ambiguity but changes recorded data; design and test-architecture agreed it is a separate, deliberate owner decision, NOT done.

**How to apply:** never claim "not read" from a Read-row absence; don't change the hook's recorded shape without the owner. See [[feedback_a_probe_is_an_instrument_that_can_be_wrong]].
