When a bug turns out to be **a violated invariant** (two fields that must agree, a registry lookup
that must match a stored value), before writing new per-case tests, grep for whether the invariant is
**already asserted somewhere** and simply applied to the wrong subset. Extending an existing
assertion to the uncovered half is cheaper, proves more, and makes regression structurally
impossible.

**Why:** 2026-10-01, `TCK-20260930-RESOURCE-NODE-YIELDS-ITEM-COLLIDES-WITH-RESOURCE-KIND`. The
compiler set `yields_item=res_spec.resource_type` (a node *kind*) where an *item id* belonged.
`tests/unit/world/test_resource_ecology.py:429,440,452` already asserted exactly the right law —
`ResourceRegistry.get(node.kind).yield_item == node.yields_item` — three times, and **only against
ecology-spawned nodes, the path that was already correct.** Nothing asserted it over
compiler-produced nodes, the path that was wrong. The suite knew the rule and only ever checked the
half that obeyed it.

Extending it to every compiler-produced node in every corpus world (one new test) revealed the real
blast radius: **23 of 24 corpus worlds failed on unfixed `main`; 24/24 passed with the fix.** Every
prior measurement had sampled 3 worlds and counted *harvest misses* (104/72/0) — those only counted
worlds where a broken node was also reached and interacted with inside the sampled tick window.
**Reachability was the limiter, not incidence.** It also closed an honestly-recorded gap: two sibling
kinds were "fixed, verified statically, never observed harvested" — the invariant proves them correct
without needing them harvested at all.

**How to apply:**
- A runtime/behavioural count measures *reached* instances; a compiled-state invariant measures *all*
  instances. Prefer the invariant for incidence claims, and don't let a behavioural sample set the
  stated blast radius ([[feedback_a_probe_is_an_instrument_that_can_be_wrong]]).
- Positive-control the new invariant against the unfixed tree — "fails 23/24 before, passes 24/24
  after" is the proof, and without it a passing invariant may simply be vacuous.
- A fix-location argument gets much stronger with incidence: "patch content, not the compiler" dies
  instantly once you know content means 23 worlds.
