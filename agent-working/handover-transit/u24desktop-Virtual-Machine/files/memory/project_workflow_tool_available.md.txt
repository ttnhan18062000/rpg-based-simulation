Since at least 2026-09-29, the Claude Code `Workflow` tool is available in this environment. The
repo's docs (docs/ai/skills.md, TCK-20260708-SKILL-CREATE-TICKETS-WORKFLOW-TOOL-STALE) still say
it isn't, and the skills hand-translate `.claude/workflows/*.js`.

The repo scripts do NOT run in it as written:
- they call `bash()`, which the runtime doesn't provide
- 3 files have unescaped template backticks
- `Workflow({name})` resolves the MAIN checkout's copy, not the worktree's

**Why:** the user wants to use Workflow more if it proves good. They approved porting
create-tickets.js first as a measured pilot against a recorded hand run.

**How to apply:** until a script has been ported, hand-execute the skill and don't offer "run the
workflow" for these scripts. Details and the baseline run are in the agent-working-design handover.
