`.gitignore` ignores `stored_artifacts/**/*.json` (only `manifest.json` is excepted). Evidence files written as `.json` pass locally but are missing in a clean checkout and CI. PR #268's runtime-probe outputs were never committed this way, and PR #270's first CI run failed on a classification table.

**Why:** found by agent-working-implementer on 2026-10-01 by reproducing the CI lane from a clean clone.
**How to apply:** tell planners and implementers to store cited evidence as `.jsonl` or `.md`, and check `git ls-files` for any file a ticket or test cites before calling it done. Related: [[feedback-ci-repro-never-from-tmp]].
