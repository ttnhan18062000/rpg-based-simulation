`docs/brainstorm/simulation_capabilities.html` was created to be a non-developer-readable translation of `docs/brainstorm/rpg_feature_atlas.html` (the dev-facing engineering atlas) — same underlying findings, but stripped of code references, file paths, class names, and implementation/investigation rationale, leaving only what each feature is and does in gameplay. Uses a simplified three-tier status (`live` / `built, not yet active` / `planned`) instead of the atlas's six-tier badge scheme (`done`/`partial`/`skeleton`/`orphan`/`gated`/`gap`).

Published as its own Artifact, separate URL from the atlas. As of creation: 13 sections, 77 cards, covering everything from a single character up through parties, cities, nations, peoples, and the world.

**Supersedes** `docs/brainstorm/entity_capabilities.html` ("Character Capabilities"), an earlier, narrower non-dev doc scoped to Entity only. Per explicit user decision, `entity_capabilities.html` was left in place but not deleted or redirected — it's stale/redundant now, not actively maintained. If a future session touches Entity-layer content, prefer `simulation_capabilities.html` as the canonical non-dev doc; don't update the old one.

**Standing sync rule**: see [[feedback_sync_capabilities_with_atlas]] — every atlas edit with a gameplay-visible consequence must be mirrored here in the same turn, not batched or skipped.
