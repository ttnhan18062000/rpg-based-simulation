When a side branch's substantive commits are **folded** (cherry-picked / re-applied) into a delivery
branch and that branch squash-merges, the fold carries only the commits someone chose to fold. A
later `agent-monitoring: flush … tool shard before branch switch` commit on the side branch is
**not** among them, so the side branch's shard can hold rows that never reach `main`.

**Confirmed 2026-10-03, `own-01-derived-stats-evidence`.** Its two substantive commits
(`758eae4ff`, `6b5597fc6`) were folded into `goal-dispatch-objective-kind` and squash-merged as
`6d630250d` (PR #284). The substantive files then diffed **byte-identical** against `origin/main` —
which is what made it look retirable. But its own tip commit `196ce0813` was a shard flush, and
`agent-monitoring/data/2026-W40/own-01-derived-stats-evidence.tools.jsonl` held **104 rows on the
branch vs 67 on `main`**. Deleting the branch would have silently dropped 37 tool rows.

**Why:** the substantive-file diff being empty is the natural "it landed, retire it" signal, and it
is genuinely empty — the gap is in a file nobody thinks to check, in a directory CLAUDE.md
specifically says must never be left behind. Monitoring data is append-only history that nothing
else reconstructs.

**How to apply:** before deleting any folded branch, diff **both** halves against `origin/main` —
the substantive files *and* `agent-monitoring/data/*/`. If the shard is behind, check whether
`main`'s rows are a strict prefix of the branch's (`head -<N> branch.jsonl | diff - main.jsonl`): a
clean prefix means the tail is purely new and can be appended with no duplicate risk, which avoids
the ratchet problem in [[project_never_raise_duplicate_run_ratchet]] and the filtering work in
[[feedback_resolve_shard_conflicts_by_filtering_consolidated_rows]]. Fold the tail into the next
batch that touches a ticket file rather than opening a monitoring-only PR — proportionate per
[[feedback_agent_tooling_checks_proportionate]]. Keep the branch until then; it costs nothing, and
deletion is the irreversible direction. Also check for **near-duplicate branch names** (here a
singular-`stat` draft branch sat beside the plural one and the handover named only one).
