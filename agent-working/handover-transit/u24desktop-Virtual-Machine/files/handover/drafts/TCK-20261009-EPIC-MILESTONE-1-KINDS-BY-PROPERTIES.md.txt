# TCK-20261009-EPIC-MILESTONE-1-KINDS-BY-PROPERTIES

## Title
Epic, foundation Milestone 1: every kind is defined by coarse properties, judged by one appraisal, and handled by decision code that never branches on a name.

## Status
EPIC_SCOPED

## Tier
epic

## Type
feature

## Priority
P1

## Request Summary
The user confirmed the foundation path, milestones 0 to 3 (roadmap section 12 on the designer branch `milestone-animal-ways`, 2026-10-09). Milestone 1 STARTS ONLY AFTER Milestone 0's gate: broke workers earn and eat in all three worlds, meat-eaters eat their kills, nobody is fed free, and the free meal is removed for every kind. Each milestone's owner choices go to the user when it starts.

## Scope
Draft children, to be sequenced when Milestone 0 is done. Each has a design to rpg-planner first.
1. Property model, part 2: extend the decision-50 coarse bands, beyond Lane A's hunting batch (size, power, wits, diet, edibility), to speed, temperament, group habit, home range, activity period, senses and signals, hazard tolerance, reproduction, and keeps-coin-and-trades. The schema, the validator, and generic archetypes migrated onto it.
2. One appraisal: the hunting batch's appraisal module becomes the single source for threat, wariness and opportunity. Estimated, never true stats (`tactical_threat.py:75` and `power.py:58` are retired as true-stat reads).
3. Kind = species, with occupation as a separate field. Untangle kind, role and archetype in content and state; check the perf Phase B file list.
4. Honest perception: sense profiles and signal defaults per body (no humanoid fallback, `gate.py:190`; per-body signals, `behavior_consumers.py:79-97`).
5. Activity period per kind (diurnal, nocturnal) and hazard tolerance per body (replacing faction-level hazard endurance with a body property, if the owner rules so).
6. Retire name branching in decision code, in measured stages. This adds a probe and architecture test, "no role, kind or faction-name checks in decision paths", then removes each branch with a pinned 5x3 per stage. Known site: `src/world/camp.py:75/158` (`goblin_warrior if kind=='goblin' else orc_warrior`).
7. Gate test: a NEW kind added from content alone (no code) behaves correctly: it eats, flees, hunts and rests according to its properties.

## Out of Scope
- Milestones 2 (nothing from nothing) and 3 (healing, food spoilage, fire), which are separate epics.

## Acceptance Criteria
- The "no name checks in decision paths" probe passes, and a new kind works from content alone.
