Design Merit Scorecard

A way to judge whether an RPG design idea is actually good — before any of it runs. Not a replacement for Simulation Quality (SimQ), which measures a running world. This measures the design, from the documents alone.

Why this needs to exist

SimQ already draws the boundary that makes this necessary — it explicitly refuses to answer the question this scorecard is for.

“This module scores simulation health: whether each subsystem is alive, balanced, and producing emergent output. It does not score correctness (that is hard_law_monitor), performance (that is perf_baseline_policy.md), or content quality (human judgment).”

docs/simulation_quality/quality_scoring_contract.md §1, Purpose & Scope

SimQ measures 10 real pillars (Cognition, Agency, Combat, Faction, Economy, Progression, Social, Information, World Dynamics, Narrative) by counting events from an actual run — belief_updated, route_selected, commitment_complete, and so on. That machinery is real, live, and exactly right for what it does. It cannot help decide whether a proposed feature is worth building, because nothing has run yet to produce events.

This scorecard is the structured version of the “human judgment” SimQ hands off to — applied consistently across 65 design ideas instead of once per idea, ad hoc, in whoever's head happened to be reading that day.

The seven axes

Each idea gets scored on all seven, independently — deliberately not collapsed into one number. Three axes reuse data already sitting in rpg_feature_atlas.html; four are new. All except Pillar Reach run 0–5, low to high.

1 · new

Direction Fit

Does this idea's core mechanism embody one of The Unwritten World's 8 principles — not just brush against it?

5 = the idea only makes sense because of a principle. 0 = no real connection, could belong to any RPG.

source: re-read against the_unwritten_world.html

2 · new

Narrative Generativity

Does this create a genuinely new shape of story, or deepen a loop that already exists? (The “new story, not new number” test.)

5 = enables stories that were structurally impossible before. 0 = purely mechanical, no narrative surface at all.

source: judgment call, cross-checked against existing Design Ideas for duplication

3 · reused

Groundedness

How much of this idea rests on verified, cited code — versus how much is still speculation?

5 = every claim checked against real source, corrections folded in where wrong. 0 = untested assertion.

source: badge tier (done/partial/gap/gated/orphan) + Cross-Cutting Risk correction history

4 · new

Pillar Reach

How many of SimQ's 10 real pillars would this idea strengthen once it's actually built and running?

Raw count, 0–10 — deliberately not normalized to the 0–5 scale yet (see Reshape Notes). The bridge back to eventual runtime measurement.

source: cross-reference against quality_scoring_contract.md §5's Pillar Metadata table

5 · reused

Efficiency

Is this cheap to build because it reuses something real, or does it need to be built from nothing?

5 = rides an existing live system almost as-is. 0 = no reuse shortcut found anywhere.

source: Shared Implementation Opportunities section

6 · reused

Risk-Adjusted Cost

Higher score means safer — low blast radius, low chance of a silent regression.

5 = contained, low-risk, no flag needed. 0 = wide blast radius, correctness-severity concerns, needs staged rollout.

source: Cross-Cutting Risk + Implementation Patterns flag recommendation

7 · reused

Leverage

How many other ideas depend on this one landing first?

5 = a hub other ideas cite repeatedly. 0 = a leaf, nothing downstream needs it.

source: Suggested Build Order in-degree

Reshape notes

Explicit open questions, not settled decisions. This is a v1 built to be argued with.

  1. Should Pillar Reach be normalized to 0–5, or does keeping it a raw count (out of 10) matter for something the other axes don't capture?
  2. Should the seven axes ever collapse into one composite score? Leaning no — this project has real history with SimQ score-gaming (a documented ceiling-fix, a standing rule against forcing an unrealistic route just to move a number) and a single Merit Score would invite the same failure mode. An unweighted, always-visible scorecard is probably the safer default, permanently, not just for v1.
  3. Who scores Direction Fit and Narrative Generativity? These are the two genuinely subjective axes. Worth deciding whether they need a second, independent read before being treated as settled — the same discipline already applied to Cross-Cutting Risk's own findings.
  4. Should pure investigation/governance ideas (9, and the resolved 15–19) be excluded from scoring entirely, rather than scored and landing near zero on every RPG-facing axis? Idea 9's row above argues a low score is still informative — but it's a real question whether “doesn't apply” should be a distinct state from “scores badly.”
  5. Not yet applied to all 65 — only four worked examples exist. Full application, if this framework survives contact with more ideas unchanged, is separate follow-up work.
