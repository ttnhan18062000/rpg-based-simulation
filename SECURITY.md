# Security Policy

This policy covers the code in this repository.

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Please do not open a public issue for a security problem.

## Scope and support

- Only the `main` branch is supported; there are no maintained release branches.
- This is a hobby project: there is no support and there are no response-time promises.
